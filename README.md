# CYBERWORLD

A responsive social-networking front-end starter for the CYBERWORLD concept.

## Included
- Earth-inspired brand logo and Earth-from-space login background
- Responsive login and sign-up screens
- Demo social feed with sample posts and interactive likes
- Responsive mobile layout
- Starter structure for future authentication, database, messaging, and live video work

## Run locally
Open `index.html` in a browser. For best results, use VS Code with the Live Server extension or any simple static web server.

## Important
This is a front-end prototype, not a production social network. Login, sign-up, password recovery, GitHub sign-in, post persistence, messaging, uploads, and live streaming are not connected yet. Do not collect real passwords or personal information with this demo. A secure backend and database must be added before public launch.

## Suggested next steps
1. Create a new GitHub repository named `CYBERWORLD`.
2. Upload all files and folders in this project.
